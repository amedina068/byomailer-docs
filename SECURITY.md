# Security policy

## A security problem in BYOMailer

Report a security problem in the BYOMailer app to the app repository. Do not open a public issue, a discussion or a pull request.

1. Read the [security policy of the app](https://github.com/amedina068/byomailer/blob/main/SECURITY.md).
2. Report the problem in private with the [advisory form of the app](https://github.com/amedina068/byomailer/security/advisories/new).

## A security problem in the docs site

You can report a problem in the docs site itself in private in this repository. For example, report a script injection on a page or a link that sends readers to a harmful site.

1. Open the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Fill in the form and submit it.

Do not put real tokens, keys or email addresses in the report.

## What happens next

One person maintains BYOMailer, so answers are not immediate. The maintainer reads each report and replies in the advisory.
